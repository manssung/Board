## 테스트 중 수정

공통 자릿수 제한 제거 후 잘못된 시각도 적용되는 문제가 있었다. 템플릿에 시·분 쌍이 명시된 조건에는 시 0~23, 분 0~59의 정수 검사를 추가했다. 금액과 기간의 일반 자릿수 제한은 다시 도입하지 않았다.

## 남은 확인 사항

- XML의 기본값만으로 판단한 소수 지원 여부와 MINUS_NOT_USE가 없는 항목의 음수 허용 여부는 실제 HTS와 다를 수 있다.
- 기간, 비율, 금액의 실제 최소·최대 허용치는 미확인 항목이 있다. 앱에서 입력·적용된다는 사실이 HTS의 허용을 의미하지 않는다.
- 복잡한 체크·라디오 분기, 날짜 조건 등은 확인 필요로 유지한다.
- 이번 결과는 로컬 대표 시나리오 QA이며 외부 사용자를 모집한 사용성 테스트나 운영 분석/API 테스트가 아니다.
