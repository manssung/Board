# 증권사 공통 상세설정 적용

로컬 시범 화면: http://localhost:3000/?preview=condition-settings

증권사·원본 파일·태그·조건 이름을 대조합니다. 파일 연결이 다르면 동일 이름과 태그의 모든 후보 구조가 같을 때만 연결합니다. 충돌, 숨은 라디오, 체크 분기, 날짜 입력, 복수 문장 연결은 추측하지 않고 기존 문장 편집을 유지합니다. KB 거래대금 예외는 원본 파일과 태그까지 제한합니다.

| 증권사 | 전체 | 숫자 입력 | 상세 설정 | 확인 필요 |
|---|---:|---:|---:|---:|
| 신한증권 | 927 | 31 | 539 | 357 |
| KB증권 | 973 | 37 | 460 | 476 |
| 교보증권 | 655 | 46 | 373 | 236 |
| LS증권 | 1074 | 43 | 290 | 741 |
| 미래에셋증권(해외) | 724 | 45 | 308 | 371 |
| 미래에셋증권 | 964 | 65 | 362 | 537 |
| NH증권 | 803 | 38 | 333 | 432 |

확인 필요에는 수정 항목이 없는 고정 문장도 포함됩니다. 이는 현재 XML 기준 구조 분류이며 실제 HTS 화면과의 전수 대조를 의미하지 않습니다. 설정 적용 전까지 기존 문장을 보존합니다. 상세설정 UI는 개발 환경에서만 표시됩니다.

## 숫자 입력 제한 보완

EDIT_LENGTH는 실제 HTS와 다른 사례가 확인되어 참고 정보로만 보관하고 공통 자릿수 제한에 사용하지 않습니다. 입력 도중 maxlength로 값을 자르지 않으며, 확인된 조건별 제한만 적용 시 검사합니다. NH 거래대금 변동폭 순위(E12_1_3 / RANK)는 사용자가 HTS에서 확인한 9999%를 기준으로 4자리 예외를 유지합니다. 미확인 조건의 입력 허용은 HTS의 실제 허용 범위를 보증하지 않습니다.
