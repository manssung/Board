# AI 기반 전략 Q&A 조건식 작성 도구

고객의 자연어 문의를 증권사별 조건검색식으로 전환하고,
작업자가 검토·수정한 뒤 답변 멘트까지 완성할 수 있도록 만든 업무 자동화 웹 도구입니다.

## Demo

- [웹 서비스 바로가기](https://board-navy.vercel.app/)

## 만들게 된 이유

증권사 Q&A 업무를 하면서 고객 문의에 맞는 조건검색식을
매번 직접 만들고 답변 멘트까지 작성하는 과정이 반복됐습니다.

조건명, 상세 설정값, AND/OR 순서가 조금만 달라도 결과가 달라질 수 있어서
빠르게 작성하면서도 다시 확인해야 하는 일이 많았습니다.

그래서 고객 문의를 입력하면 AI가 조건 후보를 먼저 추천하고,
작업자가 필요한 조건만 적용한 뒤 직접 수정할 수 있는 도구를 만들었습니다.

## 할 수 있는 것

- 증권사별 조건 목록 검색
- 고객 문의 기반 AI 조건 추천
- 추천 근거 확인 후 조건 적용 또는 제외
- 조건 직접 추가, 상세값 수정, 순서 변경
- AND/OR 및 괄호 그룹 설정
- 답변 멘트 생성·복사
- 최근 작업 임시저장 및 불러오기
