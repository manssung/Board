# 🚀 AI(Gemini API) 기반 사내 Q&A 응대 자동화 시스템

> **💡 기획 의도**
> 본 프로젝트는 UI/UX의 시각적 완성도보다, 현업의 반복적인 수동 업무(CS 및 전략 수립) 문제를 빠르게 해결하고 **LLM(Gemini API) 연동을 통한 비즈니스 로직 자동화 파이프라인을 검증**하는 데 초점을 맞춘 MVP(Minimum Viable Product)입니다.

## 🔗 Demo Link
* **웹 서비스:** [(https://board-navy.vercel.app/)] 
*(※ AI가 증권사별 비즈니스 로직에 맞춰 쿼리를 생성하는 프로토타입입니다.)*

## 1. Background & Problem (문제 정의)
* 6개 메이저 증권사 B2B Q&A 게시판을 전담 운영하며, 매일 발생하는 수십 건의 단순/반복적 조건검색 전략 생성 업무가 부서 전체 리소스의 큰 비중을 차지함.
* 담당자가 수동으로 로직을 짜고 텍스트를 타이핑하면서 발생하는 시간 낭비 및 **휴먼 에러(수기 오타)** 위험 존재.

## 2. Solution (해결 방안)
* 단순히 문제를 리포팅하는 것을 넘어, **직접 코드를 작성하여 프로세스를 자동화하는 웹 툴** 기획 및 개발.
* Google Gemini API를 도입하여, 고객의 자연어 문의를 입력하면 AI가 각 증권사의 복잡한 내부 로직과 제약 조건에 맞춰 정확한 답변 양식을 자동 산출하도록 시스템 구축.

## 3. Tech Stack (사용 기술)
* **Frontend:** React, JavaScript, HTML/CSS
* **AI / API:** Google Gemini API (프롬프트 엔지니어링 최적화)
* **Deployment:** Vercel, GitHub

## 4. Business Impact (주요 성과)
* ⏱️ **리소스 절감:** 답변 제작 및 검증에 소요되는 시간을 대폭 단축하여, 팀원들이 보다 고부가가치 기획/품질 검증 업무에 집중할 수 있는 '스마트 워크플레이스' 환경 조성.
* 🎯 **정확성 향상:** 수기 작성 시 발생할 수 있는 로직 오류를 원천 차단하여 서비스 응대 일관성 확보.
* 🏆 **2025 사내 혁신상 대상 수상:** 자동화 프로세스 도입의 효용성을 전사적으로 인정받음.
